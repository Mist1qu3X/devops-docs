# Восстановление публикации

1. Откройте последний запуск `Publish documentation` и определите неуспешный этап.
2. Если сборка MkDocs завершилась ошибкой, исправьте документацию и повторите локальную проверку `mkdocs build --strict`.
3. Если ошибка возникла при публикации, проверьте `pages: write` и `id-token: write` у задания deploy.
4. Внесите исправление через Pull Request и дождитесь успешной сборки и публикации.
5. Проверьте содержимое сайта по URL из окружения `github-pages`.
